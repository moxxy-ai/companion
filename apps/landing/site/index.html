Your agents need somewhere to work.

Companion is the self-hosted maintainer control plane for GitHub and AI agents. Decide what work should happen, run Codex, Claude Code, Moxxy or Companion's built-in runtime on machines you control, gather the evidence, enforce CI and policy, and keep a person in control of publication.

10-minute quickstart Read the source

Local first launch opens a trusted superadmin session on 127.0.0.1:8901; there is no account wizard. Control-plane state stays local. Repository and agent workflows reach the GitHub, model, runner, and integration endpoints you configure.

Everything is scoped to a workspace: a named group of repositories. Each module ships its own tables, routes, permissions and pages, and can be switched off at runtime.

Self-hosted, and it means it

Your control plane stays on your infrastructure.

Companion is one process, one SQLite file and a data directory. Stored secrets are never returned to the browser; connections to GitHub, model providers, runners and delivery integrations are explicit and operator-configured. Every REST route declares the permission it requires, and the interface hides what the signed-in role cannot use.

  • Three roles built inadmin, maintainer and business, enforced end to end rather than in the UI.
  • Runs on your machinesThe local box, or any number of remote runners you attach with a token.
  • Air-gap friendlyNo telemetry, update check or CDN; configured Git and model infrastructure must remain reachable.
  • MIT licensedRead it, fork it, run it. The source is the product.

Modular framework

Turn a module off and it is gone, without a restart.

A small kernel hosts feature modules that are loaded, migrated, permissioned and toggled at runtime. Disable one and its API returns 503, its navigation and routes disappear, and its permissions drop out of the grid. Which modules a build contains is a build profile; which of those are running is state you change from the admin page or the CLI.

Install

Three ways in.

npx

The published CLI carries the daemon and the built interface.

Docker

Persist /data and the moxxy home, then open port 8901.

From source

A pnpm workspace: the daemon, the shell, and one package per module.

Agent runs use a supported CLI on the execution machine or Companion's built-in runtime with a provider you configure. The dashboard starts without either.
